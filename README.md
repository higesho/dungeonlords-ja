# ダンジョンロード 日本語化パッチ

Steam 版「Dungeon Lords Steam Edition」を日本語で遊べるようにする、非公式のファンメイド日本語化パッチです。
開発元・販売元とは関係ありません。

- サイト（紹介・入れ方）: https://higesho.github.io/dungeonlords-ja/
- ダウンロード: [リリース](https://github.com/higesho/dungeonlords-ja/releases/latest) の `DungeonLords_JP.zip`
- ウィザーズ＆ウォーリアーズの日本語化: https://higesho.github.io/wizards-warriors-ja/
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
- マイト・アンド・マジック シリーズの日本語化: https://higesho.github.io/mm-ja/
- D&D シリーズの日本語化: https://higesho.github.io/dnd-ja/

## 入れ方

1. `DungeonLords_JP.zip` の中の `dinput8.dll` を、ゲームのフォルダ（`DLSteamEdition.exe` があるフォルダ）に置きます。
2. いつもどおり Steam から起動します。

外すときは、`dinput8.dll` を消せば英語版に戻ります。
ゲームのファイルは書き換えません。配布物には原作のプログラムやデータは入っていません。
